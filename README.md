# 课余 · 个人小助手

北京大学《互联网软件》课后作业：用氛围编程生成的个人向小项目。

打开即可使用，不接入真实用户数据，也不处理密钥或生产环境。待办保存在浏览器本地；课表为虚构示例数据。

## 能做什么

- **今日**：看今天的课程和待办
- **课表**：按星期查询示例课程
- **待办**：添加、完成、筛选、删除个人事项

## 怎么运行

任选一种：

```bash
# 用 Python 起一个本地页面
python -m http.server 5173
```

然后浏览器打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)

也可以直接双击打开 `index.html`。
